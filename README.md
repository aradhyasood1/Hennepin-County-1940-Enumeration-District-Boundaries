**Repository Overview and Data Introduction**

The digitized spatial boundaries for the 1940 Enumeration District (ED) maps were digitized and geocoded by the authors from historical cartographic records procured via the National Archives Catalog. The original archival source images can be accessed and downloaded directly from the National Archives using the following six catalog identifiers: ID: 5833128 (https://catalog.archives.gov/id/5833128), ID: 5833129 (https://catalog.archives.gov/id/5833129), ID: 5833130 (https://catalog.archives.gov/id/5833130), ID: 5833131 (https://catalog.archives.gov/id/5833131), ID: 5833132 (https://catalog.archives.gov/id/5833132), and ID: 5833133 (https://catalog.archives.gov/id/5833133). The resulting digitized geographic shapefile was compiled by the authors, is intended for public use, and should be cited according to the framework established by Almagro et al (2026).
